# MiniMax Code project harness

<!-- managed-by: configure-mcode-projects.sh -->

- `AGENTS.md` contains project-level coding-agent instructions.
- `CLAUDE.md` and `.cursorrules` refer to `AGENTS.md` when auto-created.
- User-level MiniMax Code configuration belongs in `~/.minimax/config.yaml`, not in the repository.
- Launch the TUI with `mcode` from the repository root. Use `/doctor` and `/status` to inspect the session.
- Update `AGENTS.md` with the *real* project build/test commands and conventions.
